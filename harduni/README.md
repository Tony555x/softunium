# Harduni

**Harduni** is a text-based, terminal Role-Playing Game (RPG). Journey through mysterious dungeons, face off against challenging enemies like the Weak Programmer and the Boss Senior Developer, and grow your character by earning XP and leveling up. The game features real-time Active Time Battle (ATB) combat, where you must wait for your energy to fill up before executing your next move.

## Controls

The game is entirely controlled via your keyboard. Because it runs in real-time, you can seamlessly type your choices while the game continues to run in the background.

- **Navigation & Combat**: Type the number (e.g., `1`, `2`, `3`) corresponding to the option you wish to select and press `Enter`.
- **Character Stats**: Type `х` or `хар` (Cyrillic) and press `Enter` at almost any time to immediately open your Character Stats panel and view your attributes, skills, and alignment.
- **Backspace**: If you make a typo, simply press `Backspace` to clear your input buffer.

## How to Run

Ensure you have the latest .NET SDK installed (version 9.0+).

1. Open your terminal and navigate to the root directory of the project.
2. Run the game using the .NET CLI:
   ```bash
   dotnet run
   ```
